# 🤝 Contribuindo para o Processo de Desenvolvimento\n\nObrigado por querer melhorar este processo! Este guia explica como contribuir.\n\n## Como Este Processo Funciona\n\nEste repositório contém um **processo estruturado de desenvolvimento** em 10 fases:\n\n```\nFASE 0 → FASE 1 → FASE 2 → ... → FASE 10\nPRE      DESIGN    SETUP      DEPLOY\n```\n\nCada fase tem:\n- 📋 README.md - Overview\n- ✅ Checklist.md - O que fazer\n- 📚 Guias e templates\n- 🤖 Prompts para Claude IA\n\n## Como Usar Para Seu Projeto\n\n### 1. Clone Este Repositório\n```bash\ngit clone https://github.com/seu-repo/ai-coding-process.git\ncd ai-coding-process\n```\n\n### 2. Customize para Seu Projeto\n\n**Arquivos a editar:**\n- `README.md` - Colocar nome do seu projeto\n- `.ai/contexto-projeto-template.md` → `.ai/contexto-projeto.md`\n- `planejamento/00-PRE-DESENVOLVIMENTO/prd.md` - Seu PRD\n\n**Não altere:**\n- Estrutura das fases\n- Templates dos documentos\n- Prompts para Claude (usar como está)\n\n### 3. Comece na FASE 0\n\nSiga o processo passo a passo:\n1. Leia FASE 0 README\n2. Siga o checklist\n3. Crie seus documentos\n4. Quando completo, vá para FASE 1\n\n## Melhorando Este Processo\n\n### Encontrou um Erro ou Gap?\n\n1. Abra uma [Issue no GitHub](https://github.com/seu-repo/issues)\n2. Descreva o problema\n3. Sugira uma solução (opcional)\n\n### Quer Contribuir com Melhorias?\n\n1. **Fork** o repositório\n2. Crie uma **branch** para sua feature\n   ```bash\n   git checkout -b melhoria/nome-da-melhoria\n   ```\n3. **Commit** suas mudanças\n   ```bash\n   git commit -m \"Melhoria: descrição clara\"\n   ```\n4. **Push** para sua fork\n   ```bash\n   git push origin melhoria/nome-da-melhoria\n   ```\n5. Abra um **Pull Request**\n\n### Tipos de Contribuições Bem-Vindas\n\n✅ **Documentação**\n- Esclarecer instruções confusas\n- Adicionar exemplos\n- Melhorar estrutura\n\n✅ **Novos Templates**\n- Para novas tecnologias (ex: Mobile with React Native)\n- Para diferentes stacks (ex: Python/Django)\n- Para casos especiais (ex: Monorepo)\n\n✅ **Prompts Melhorados**\n- Prompts mais específicos\n- Prompts para novos cenários\n- Exemplos com melhores resultados\n\n✅ **Guias e Exemplos**\n- Walkthroughs completos\n- Screenshots\n- Vídeos tutoriais (links)\n\n❌ **Não Aceitamos**\n- Alterações que mudem fundamentalmente as 10 fases\n- Recomendações de ferramentas proprietárias (ex: promover uma ferramenta específica)\n- Conteúdo não relacionado ao desenvolvimento web\n\n## Padrões de Contribuição\n\n### Documentação\n- Use Markdown\n- Headers com emojis (`# 🎯 Título`)\n- Links relativos (`[Link](./arquivo.md)`)\n- Código com syntax highlighting\n\n### Templates\n- Use placeholders com `[PLACEHOLDER]`\n- Adicione instruções de customização\n- Mantenha compatível com as 10 fases\n\n### Prompts\n- Comece com claro `# PROMPT: Nome`\n- Estruture com sections claras\n- Inclua exemplo de output esperado\n- Teste com Claude antes de submeter\n\n## Code of Conduct\n\nEste projeto adota um [Código de Conduta](./CODE_OF_CONDUCT.md):\n\n- ✅ Seja respeitoso\n- ✅ Bem-vindo é para todos\n- ✅ Críticas construtivas\n\n- ❌ Assédio de qualquer tipo\n- ❌ Discriminação\n- ❌ Conteúdo ofensivo\n\n## Processo de Review\n\nQuando você abre um PR:\n\n1. **Automático**: Testes básicos (se houver)\n2. **Revisor**: Um mantenedor revisa\n3. **Discussão**: Feedback ou pedido de mudanças\n4. **Aprovação**: Merge quando OK\n5. **Publicado**: Incluído na próxima versão\n\n## Dúvidas?\n\nSe tem dúvidas:\n\n1. Procure nas [Issues existentes](https://github.com/seu-repo/issues)\n2. Leia a [Documentação](./README.md)\n3. Abra uma [Discussão](https://github.com/seu-repo/discussions)\n\n## Agradecimentos\n\nObrigado por contribuir! 🎉\n\nSeus PRs ajudam a fazer este processo melhor para todos.\n\n---\n\n**Primeira Contribuição?** Procure por issues com label `good-first-issue`!\n\n---\n\n**Versão**: 1.0\n**Última atualização**: Nov 2024\n"
