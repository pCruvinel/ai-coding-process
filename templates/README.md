# 📝 Templates de Código

> Templates e exemplos de código para copiar e adaptar em seus projetos

## 📂 Estrutura

```
templates/
├── README.md              ← Você está aqui
├── components/            ← Componentes React exemplo
├── hooks/                 ← Custom hooks exemplo
├── lib/                   ← Utilities e helpers
└── types/                 ← TypeScript types comuns
```

## 🎯 Como Usar

1. **Copie o template** necessário para seu projeto
2. **Adapte** para suas necessidades específicas
3. **Remova** comentários `// EXEMPLO` quando finalizar
4. **Siga** os padrões em `.claude/skills/02-padroes-codigo/`

## 📋 Templates Disponíveis

### Componentes
- `components/server-component-example.tsx` - Server Component com fetch
- `components/client-component-example.tsx` - Client Component com estado
- `components/form-example.tsx` - Formulário com Zod validation
- `components/list-example.tsx` - Lista com estados loading/empty/error

### Hooks
- `hooks/use-data-example.ts` - Hook para fetch de dados
- `hooks/use-auth-example.ts` - Hook de autenticação

### Lib
- `lib/supabase-server-example.ts` - Cliente Supabase server
- `lib/supabase-client-example.ts` - Cliente Supabase browser
- `lib/validation-example.ts` - Schemas Zod exemplo

### Types
- `types/common-types.ts` - Types comuns

**Nota**: Estes são templates de referência. Adapte conforme necessário para seu projeto específico.
