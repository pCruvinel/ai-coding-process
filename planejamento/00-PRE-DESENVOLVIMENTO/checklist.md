## 🎤 DURANTE A ENTREVISTA

### Contexto Geral
- [ ] Qual é a visão geral do projeto?
- [ ] Por que este projeto é importante?
- [ ] Qual é o objetivo principal?
- [ ] Qual é o contexto do negócio?

### Problema & Solução
- [ ] Qual problema você está tentando resolver?
- [ ] Por que esse problema é importante?
- [ ] Qual é a solução esperada?
- [ ] Como você imagina a aplicação funcionando?

### Usuários & Personas
- [ ] Quem são os usuários principais?
- [ ] Qual é o perfil deles (age, profissão, tech-savvy)?
- [ ] Quais são seus objetivos ao usar a app?
- [ ] Quais são seus problemas/necessidades?
- [ ] Quanto tempo eles podem/querem usar a app?

### Features MVP (MVP = Minimum Viable Product)
- [ ] Quais são as features ESSENCIAIS para lançar?
- [ ] Em que ordem elas devem ser implementadas?
- [ ] Qual é a prioridade de cada feature?
- [ ] Há dependências entre features?

### Features Pós-MVP
- [ ] Quais features gostariam de adicionar depois?
- [ ] Em que timeline? (próximos 3, 6, 12 meses?)

### Requisitos Não-Funcionais
- [ ] Quantos usuários simultâneos são esperados?
- [ ] Qual é a disponibilidade esperada (uptime)?
- [ ] Há requisitos de segurança/conformidade?
- [ ] Dados sensíveis? (LGPD, GDPR, etc)
- [ ] Integrações com sistemas externos?

### Timeline & Budget
- [ ] Qual é a data de lançamento esperada?
- [ ] Existem datas importantes?
- [ ] Qual é o budget do projeto?
- [ ] Como será o pagamento? (milestones, fixo, etc)

### Métricas de Sucesso
- [ ] Como você saberá que o projeto foi bem-sucedido?
- [ ] Qual é a métrica primária?
- [ ] Existem métricas secundárias?
- [ ] Qual é o alvo numérico? (ex: 1000 usuários em 3 meses)

## 📞 Quando Você Fica Preso

### Problema: Cliente não responde
**Solução**:
- Envie um email com perguntas MÚltipla Choice
- Agende uma call de 30 min
- Comece com o MVP mínimo possível

### Problema: Cliente muda de ideia frequentemente
**Solução**:
- Documente CADA mudança
- Peça aprovação por escrito
- Defina "congelamento de escopo" na data X

### Problema: Features muito vagas
**Solução**:
- Peça exemplos concretos
- Mostre screenshots de apps similares
- Pergunte: "O que o usuário faria especificamente?"
