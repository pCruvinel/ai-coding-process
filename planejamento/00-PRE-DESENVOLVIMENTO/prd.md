# 📋 Product Requirements Document (PRD)

## 🚧 Como Usar Este Arquivo

Este é o arquivo onde você criará o PRD do **seu projeto específico**.

### Opção 1: Usar o Template (Recomendado)
1. Copie todo o conteúdo de [`template-prd.md`](./template-prd.md)
2. Cole neste arquivo
3. Preencha cada seção com as informações do seu projeto
4. Delete esta seção de instruções quando terminar

### Opção 2: Gerar com Claude IA
1. Use o prompt em [`prompt-entrevista.md`](./prompt-entrevista.md)
2. Responda as perguntas do Claude
3. Claude gerará o PRD completo
4. Cole o resultado neste arquivo
5. Revise e ajuste conforme necessário

### Opção 3: Referência do Exemplo
1. Veja [`exemplo-prd.md`](./exemplo-prd.md) para inspiração
2. Adapte para seu contexto
3. Preencha este arquivo

## ✅ Checklist Antes de Finalizar

Antes de considerar seu PRD completo, verifique:

- [ ] Todas as seções do template estão preenchidas
- [ ] Nenhuma seção tem `[PREENCHER]` ou placeholder
- [ ] Pelo menos 2-3 personas estão bem definidas
- [ ] Features MVP estão claras (5-10 features)
- [ ] Features pós-MVP estão identificadas
- [ ] Timeline e budget foram discutidos
- [ ] Métricas de sucesso estão definidas
- [ ] Cliente revisou e aprovou o documento
- [ ] Aprovação está documentada (email, assinatura, etc)
