# 🎨 FASE 1: DESIGN FRONTEND

## Visão Geral
Criar todas as telas e componentes visuais da aplicação usando Lovable ou v0.

**Duração estimada**: 3-5 dias
**Responsável**: Designer/PM + Cliente

## 🎯 Objetivos
1. Converter PRD em wireframes/designs visuais
2. Criar todas as telas principais
3. Definir componentes reutilizáveis
4. Obter aprovação visual do cliente
5. Exportar código limpo para GitHub

## ✅ Checklist Rápida
- [ ] Brief de design criado
- [ ] Telas mapeadas (todas do PRD)
- [ ] Design responsivo (mobile + desktop)
- [ ] Componentes identificados
- [ ] Estados (loading/error) desenhados

- [ ] Código exportado para GitHub

## 📋 Telas Principais (Exemplo)
Para TaskFlow (exemplo do PRD):
1. **Login/Signup** - Autenticação
2. **Dashboard** - Visão geral de projetos
3. **Detalhes do Projeto** - Kanban com tarefas
4. **Criar/Editar Projeto** - Modal ou página
5. **Admin Panel** - Gerenciar usuários
6. **Perfil de Usuário** - Settings

## 🛠️ Ferramentas Recomendadas
- **Lovable** (lovable.dev) - Melhor para MVP rápido
- **v0** (v0.dev) - Alternativa boa, usa Shadcn UI
- **Figma** - Se quiser design offline antes de código
