# 🚀 Guias Avançados

Esta pasta contém guias opcionais para funcionalidades avançadas que não fazem parte do fluxo MVP básico.

## 📚 Guias Disponíveis

### [N8N - Automações e IA](./N8N/README.md)
**Quando usar**: Quando seu projeto precisa de workflows de IA complexos, processamento assíncrono ou integrações com múltiplos serviços.

**Casos de uso**:
- Processamento de documentos com IA (PDFs, imagens)
- Workflows multi-step (ex: upload → análise → notificação)
- Integrações com APIs externas
- Automações baseadas em eventos
- Processamento em background

**Não usar no MVP**: A menos que seja um requisito crítico do projeto.

---

## 🎯 Como Usar Estes Guias

1. **MVP Primeiro**: Complete as fases 0-10 do processo principal antes de adicionar funcionalidades avançadas
2. **Avalie Necessidade**: Confirme que a funcionalidade é realmente necessária
3. **Planeje Integração**: Veja como integrar com sua arquitetura existente
4. **Documente**: Adicione decisões técnicas em `.ai/decisoes-tecnicas.md`
