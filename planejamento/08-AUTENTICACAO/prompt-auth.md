# 🔐 Prompt: Implementação de Autenticação

Use este prompt com Claude IA para implementar autenticação completa no projeto.

---

## 🎯 Contexto

Você é um desenvolvedor fullstack implementando autenticação com Supabase Auth em Next.js App Router.

**Stack**: Next.js 14+, TypeScript, Tailwind v4, shadcn/ui, Supabase Auth

---

## 📋 Tarefa

Implemente sistema completo de autenticação seguindo o guia em `guia-auth.md`.

**Inclua**:
1. Páginas: login, signup, reset-password
2. Componentes de formulário com validação
3. Middleware para proteção de rotas
4. Hook useUser
5. Componente de logout

**Requisitos**:
- TypeScript com tipos corretos
- Tratamento de erros adequado
- Loading states
- Validação de formulários
- Acessibilidade básica (labels, autocomplete)
- Responsive design

---

## ✅ Checklist de Implementação

- [ ] Estrutura de pastas criada
- [ ] Login/Signup/Reset funcionando
- [ ] Middleware protegendo rotas
- [ ] useUser hook implementado
- [ ] Redirecionamentos corretos
- [ ] Mensagens de erro claras
- [ ] Testes manuais completos
