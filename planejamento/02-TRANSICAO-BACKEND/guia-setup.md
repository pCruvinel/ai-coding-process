# 🔄 Guia: Setup Inicial do Projeto\n\n## 1. Preparar Repositório\n\n```bash\n# Clone do projeto que foi exportado do Lovable/v0\ngit clone <url-do-repositorio> <nome-projeto>\ncd <nome-projeto>\n\n# Criar branch de desenvolvimento\ngit checkout -b develop\ngit push -u origin develop\n```\n\n## 2. Instalar Dependências\n\n```bash\nnpm install\n# ou\nyarn install\n```\n\n## 3. Setup Variáveis de Ambiente\n\n```bash\n# Copiar template\ncp .env.example .env.local\n\n# Editar .env.local com suas variáveis\n# Você vai preencher depois quando criar Supabase\n```\n\n**Variáveis essenciais**:\n```\nNEXT_PUBLIC_SUPABASE_URL=https://xxx.supabase.co\nNEXT_PUBLIC_SUPABASE_ANON_KEY=xxx\n```\n\n## 4. Testar App Localmente\n\n```bash\nnpm run dev\n# Abrir http://localhost:3000\n```\n\nVocê deve ver:\n- ✅ App carregando\n- ✅ Nenhum erro no console\n- ✅ Design corresponde ao que foi aprovado\n\n## 5. Configurar ESLint e Prettier\n\n```bash\n# ESLint\nnpm run lint\n\n# Prettier (auto-format)\nnpm run format\n```\n\n## 6. Criar Estrutura de Pastas Adicionais\n\n```bash\n# Documentação\nmkdir -p docs\n\n# Supabase migrations\nmkdir -p supabase/migrations\n\n# Tests\nmkdir -p __tests__/unit\nmkdir -p __tests__/integration\n\n# API utilities\nmkdir -p src/lib/api\nmkdir -p src/lib/supabase\n```\n\n## 7. Primeiro Commit\n\n```bash\ngit add .\ngit commit -m \"Initial commit: Frontend setup from Lovable/v0\"\ngit push origin develop\n```\n\n## 8. Próximas Etapas\n\n✅ Setup completo!\n\nPróximas fases:\n1. **FASE 3**: Documentação\n2. **FASE 7**: Setup Supabase\n3. **FASE 8**: Autenticação\n4. **FASE 9**: Desenvolvimento\n\n---\n\n## 🆘 Troubleshooting\n\n### Problema: npm install falha\n**Solução**: \n```bash\nrm package-lock.json\nnpm cache clean --force\nnpm install\n```\n\n### Problema: Porta 3000 já em uso\n**Solução**:\n```bash\nnpm run dev -- -p 3001\n```\n\n### Problema: Módulos não encontrados\n**Solução**: Verificar `tsconfig.json` e `next.config.js`\n\n---\n\n**Status**: ✅ Pronto\n**Próxima**: FASE 3 (Documentação)\n"
